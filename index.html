Audio setup, tuning guide & FAQ

Choose your audio input

Built-in microphone: simplest for acoustic guitar, ukulele and room tuning. Put the mic near the instrument and reduce background noise.

USB audio interface: recommended for electric guitar and bass. Connect to an instrument / Hi-Z input, select the interface above, and set a clean input gain.

Driver & browser permissions

  • On macOS, select the interface in the browser input list. Install the manufacturer's driver/control app if the device requires one; many class-compliant interfaces work without a separate driver.
  • On Windows, install the manufacturer's ASIO driver for DAW use. Browser microphone access generally uses the system audio driver, not a selectable ASIO driver.
  • Allow microphone access for this site. GitHub Pages uses HTTPS, which is required for microphone capture.

Getting the best reading

  • Mute other instruments and play one string at a time.
  • Use a clean, sustained note; pluck firmly, then let the note settle.
  • For bass, give the tuner a moment to detect the low fundamental.
  • For electric instruments, direct interface input usually gives the cleanest result.
