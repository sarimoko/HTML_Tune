Which audio input should I use?

Built-in microphone — easiest option. Select your MacBook, laptop, or phone microphone. Place the instrument reasonably close and reduce background noise.

USB audio interface — best for electric guitar or bass. Connect the instrument to the interface's instrument/Hi-Z input, select the interface here, and set its input gain so the signal is healthy without clipping.

  • For acoustic instruments, use the built-in mic or an external microphone.
  • For an electric instrument, use a direct interface input; do not select system output or a speaker loopback.
  • Allow microphone access when your browser asks. Headphones help prevent speaker feedback.

On macOS, check System Settings → Privacy & Security → Microphone if the browser cannot access an input. On Windows, check Settings → Privacy & security → Microphone.
